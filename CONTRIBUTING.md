# Contributing to AI-Softphone

Thanks for your interest! AI-Softphone is maintained by a small team, so please read this short page first.

## Questions and ideas

Please don't open issues for "how do I…" questions. Use the documentation first:
https://docs.ai-softphone.com. For questions and ideas, use [GitHub Discussions](../../discussions).

## Reporting bugs

Open an issue with the **Bug report** template. Include the app version, your OS and, for call problems,
your PBX or SIP provider.

**Before attaching logs or screenshots, remove personal data:** SIP passwords, phone numbers, contact
names, recordings and transcripts of real conversations. Never attach call recordings to a public issue.

## Security issues

Do not report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).

## Pull requests

- For anything bigger than a small fix, open an issue first so we can agree on the approach.
- Keep pull requests focused: one change per pull request.
- Make sure the project builds on your platform (see the README).

This is a free project. We read every issue, but we can't promise a reply time or a fix date.
