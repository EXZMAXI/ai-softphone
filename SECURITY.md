# Security policy

Please report security vulnerabilities privately, not in public issues.

Use GitHub's private reporting: **Security → Report a vulnerability** in this repository,
or email [info@ai-softphone.com](mailto:info@ai-softphone.com).

Include the affected version, your OS and steps to reproduce. We will acknowledge your report
and keep you informed while we work on a fix.

Only the latest released version receives security fixes.
